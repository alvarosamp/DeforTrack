# DeforTrack dataset

The DeforTrack dataset is available from:

https://universe.roboflow.com/alvaro-z5qmu/floresta-wgiln

The benchmark uses the following semantic partition roles:

| Partition | Images |
|---|---:|
| Training | 12,861 |
| Validation | 895 |
| Final test | 892 |

After exporting the dataset, configure the image and annotation paths through
the evaluation scripts' command-line arguments. Raw images are not duplicated
inside this Git repository.
